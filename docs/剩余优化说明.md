# 剩余优化 09—11

沿用首批暖白墨绿主题。

## 统计

- 默认展示本月，收入和支出共用总额、环比、日均、最大单笔、每日趋势、分类排行。
- 年度分析进入下一层，保留年度折线 / 柱状、同比、月度排行、历年趋势及分类逐年对比。
- 点击分类排行或环形图分类，打开对应月份 / 全年账单；归档分类也能查看历史记录。
- 查询结果携带期间和收支类型，避免切换类型时显示上一类型的统计。

## 分类

- 支出 / 收入分类均可新增、编辑、排序、归档及恢复；记账页管理入口直接进入相应类型。
- 长按右侧拖动柄排序，靠近列表边缘自动滚动；放手后批量保存，取消拖动恢复原顺序。
- 更多菜单提供编辑、上移、下移、归档、删除；归档分类默认折叠。
- 排序仅更新 sort_order，不覆盖分类名称、颜色或归档状态。
- 内置分类或有账单引用时以归档替代删除；编辑失败保留表单并显示原因。

## 设置与备份

- 外观、分类、数据、存储、高级分组；通过选项面板调整主题、背景和币种。
- 用户入口改为备份数据、恢复备份、导出表格，保存文件与分享选择收进面板。
- 恢复顺序：选文件 → 只读校验与摘要 → 可先备份当前数据 → 确认替换 → 恢复结果。
- 实际恢复使用预览时解析的快照；取消不会修改数据。
- 无效记录、无效分类、空备份均在确认前明示；账单和分类单事务替换。
- v1 备份的缺省账单 id 分配为不冲突的正整数；日期严格校验，整数分不接受小数截断。
- 数据库恢复后，设置异常单独提示；缺失自定义背景图时回落到默认背景。
- 隐藏尚未生效的周起始日设置入口，已有偏好继续保留在备份中。
