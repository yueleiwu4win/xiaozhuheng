# 绢本山水（宋式主题重设计）

选定视觉：本轮按显示顺序的第2张生成图，`song-landscape-target.png`（853×1844，约390×844逻辑视口）。替换原 `song` 风格；稳定存储标识不变，名称显示「绢本山水」。

## 页面与组件

- `SongHome.kt`：独立山水页眉、居中可选月份、左支出/右收入结余、三项收支筛选、连续细线账目。整页可滚动。
- 默认背景使用浅绢底与纸纹；首页才放山水横幅。相册/内置人物/渐变使用现有背景，不叠加山水与笔搁，避免两个主体相冲。不会更改用户已保存背景。
- `SongCreateAction` 在 Scaffold 底栏中预留区域，棕墨小角按钮、左侧毛笔笔搁。底部导航使用朴素纵排图标/标签/短选中线。
- 字体复用本地 Noto Serif SC，数字按实际宽度测量。小屏和超过130%字号时收支汇总上下排列，装饰减少。
- 记账分类、数字键盘、统计区块、设置分区和对话框复用全局主题组件与棕墨配色。
- 数据查询、搜索、月份/类型/分类筛选、编辑、保存、删除及二次确认复用既有逻辑；无成功提示和撤销条。
- 选择本主题推荐浅色，之后可改为深色；恢复备份依旧尊重备份明暗设置。
