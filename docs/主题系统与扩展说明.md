## 本轮代码梳理与墨金重排

视觉基准为 `docs/design/guofeng/ink-gold-user-target.png`（用户本次提供的 1024×1536 原稿），不再以 `03-ink-gold-v2.png` 的纵向变体作为墨金验收目标。

调用链：`MainActivity` 读取 SettingsRepository → 同时提供 LocalBackgroundSpec / BookkeepingTheme → `MainNav` 根据 HomeActionPlacement 布置通栏 CTA → `HomeScreen` 读取 HomeViewModel 状态 → `LedgerHomeContent` 分派 → **InkGoldHomeContent** 独立排版。青玉继续使用 CeladonOverview/CeladonHeader，墨金不再进入该页面的通用头部与收支三选栏。

- 月份、搜索、分类、删除继续复用 HomeViewModel → BillRepository → Room；没有新数据库或重复业务层。
- `InkGoldMasthead`：双栏品牌/月份搜索。可用宽度 <340dp 或字号 >125% 时纵向排列，整个账页滚动，避免头部占满可用空间后无法读账单。
- `InkGoldSummary`：左支出、右收入/结余；人民币使用金额紧跟「元」，其他币种保留符号；长金额测量缩放，单位设最小可读字号。
- `InkGoldCategories`：真正的启用分类列表，可横滑；选择分类会联动收支类型。“全部”同时清除 categoryId/type，保留关键词。筛选弹层仍可单独选收入或支出。
- `InkGoldBillRow`：备注主标题（无备注时显示分类）、分类副标题、单色圆形图标、右对齐金额与编辑箭头；外层保留原先滑动删除及二次确认。
- `LedgerCreateButton`：墨金改为 DOCKED，固定在底部导航上方并由 Scaffold 扣除占用空间；不再悬浮遮住账目。横向导航选中胶囊在大字体时改纵排。
- 背景配置 **不重置、不迁移**。用户偏好人物照片，因此保持相册图片和原蒙层；主题默认才绘制生成的墨绿布面纹理。`AppBackground` 负责异步读图片，`AppBackgroundContent` 负责实际绘制，照片测试复用相同绘制代码。
- 默认纹理 `ink_gold_bookcloth.png`：1024×1536，内置 imagegen 生成；提示为 #0B281F 古籍布面/细纸纤维、左侧略明显、中心均匀、无文字/UI/人物/竹叶。以 0.42 alpha 叠加主题底色。
- 正文增加完整基本汉字区等字符，防止用户备注大量回落为系统字体；APK 会随本地字库与纹理增加，不增加运行时联网依赖。

## 使用

设置 → 外观 → 界面风格，可选择「经典」「绢本山水」「青玉雅集」「墨金藏书」。每项提供实际配色预览，切换立即生效并自动记忆。
明暗模式和背景是独立选项：主题可分别使用浅色、深色、跟随系统；默认背景跟随所选主题，也可选择渐变或相册图片。
选择青玉雅集时采用推荐浅色，选择墨金藏书时采用推荐深色；风格和推荐明暗在一次设置写入中切换，用户随后可单独更改明暗。
恢复备份不应用推荐明暗，保留备份里的实际选择；缺少明暗字段时不改当前明暗。
旧安装缺少风格字段时使用经典；旧备份缺少风格字段时保留当前选择，新备份包含风格。

宋式书账适配明细、记账键盘、统计、设置、分类管理和通用弹窗：暖白纸色、宋体短标题、墨绿主操作、浅玉选中态、账页分隔、线性分类图标、低饱和分类配色与淡竹叶。深色使用墨绿底和淡金主操作。金额与正文使用易读字体，分类数据库内容保持原有标识。

青玉雅集对应已选的第二张参考图：淡玉圆角概览、居中金额、圆形品牌图、墨绿圆润操作、浅玉线性分类、底部宽幅记账按钮。宽幅按钮位于 Scaffold 底栏中，列表获得正确可用空间，不覆盖账单。

墨金藏书对应第三张参考图：墨绿账页、暖白金额、淡金主操作、算盘品牌标记、账页分隔、书签式筛选与导航。也提供浅色变体，手动改为浅色时采用纸白与古铜配色。

两套主题使用独立首页排版，查询、筛选、保存、删除、统计、备份继续共用原有业务层。首页使用宋体正文与金额；统计和设置同步字体、分区与紧凑留白，记账分类缩短多余高度，键盘保留系统数字字体。过滤面板保持不透明表面。参考图对应「主题默认」背景，用户自选的渐变或照片仍保留。

小屏按页面实际可用高度收紧首页头部、概览与日期间距；大字号下月份按宽度测量，收支汇总在超过 150% 字号时改成上下排列。长金额优先测量字号，必要时完整换行，避免截掉数字。

## 结构

- `data/prefs/ThemeStyle.kt`：持久化标识、显示名称、简介；未知标识回退经典。
- `ui/theme/ThemeDefinition.kt`：主题注册表，明暗颜色、字体、Material 形状与组件规则。
- `ui/theme/Theme.kt`：将所选主题提供给整棵 Compose 页面树。
- `ui/common/ThemeComponents.kt`：按钮、筛选、图标、分类显示色、账页分隔的统一入口。
- `ui/home/LedgerHome.kt`：青玉/墨金的概览、筛选、日期、账目及响应式规则；只消费状态和回调，不访问数据库。
- `ui/home/LedgerNavigation.kt`：两套主题的记账按钮与导航。
- `app/src/visualQa`：可选的原生截图用例；`app/src/test/snapshots/images` 保存已检查的基准。
- `SettingsRepository`：风格单独保存为 `theme_style`，与明暗模式 `theme_mode` 独立。
- `SettingsBackup.kt`：JSON 设置序列化；v2 格式增加可选 `themeStyle`，旧读取端仍可忽略。

## 继续增加风格

1. 在 `ThemeStyle` 添加稳定英文标识、名称和简介。已经发布的标识不改名。
2. 在 `ThemeRegistry` 注册新的 `ThemeDefinition`，定义浅/深配色、标题字体、形状和 `ThemeTokens`。概览排版、筛选样式、导航样式、主操作位置通过枚举规则区分。
3. 如有装饰图，使用本地资源；可嵌入字体的许可证放在 `assets/licenses`。无需运行时联网。
4. 颜色与小组件继续共用规则；大幅改变页面结构时新增独立布局，通过 `HomeLayout` 等声明式规则选择，避免强行复用默认布局。
5. 设置列表读取 `ThemeStyle.entries`，备份直接保存稳定标识，支持新增主题。
6. 验证旧安装、未知标识、明暗组合、备份回读，并在真机检查字体缩放、长金额、分类滚动和返回。

主题区分为排版层、组件层与配色层。独立布局不需要复制 Repository、ViewModel 或数据库，也不需要拆成两个软件。
