# 记账键盘与加减计算（1.1.10）

## 1.1.10 输入法切换优化

1.1.9使用整页imePadding并在输入法首次可见时移除金额键盘、完全隐藏后重新创建，容易造成分类区先扩大再缩小以及按键重新组合。

改为EntryKeyboardDock常驻金额键盘，在布局阶段读取输入法高度；底部区域高度取金额键盘与输入法的较大值。金额键盘停在窗口底部，由系统输入法覆盖和露出，备注只跟随必要的高度差移动。移除整页imePadding及按输入法可见性移除组件的分支。顶部完成按钮只通过derivedStateOf订阅是否可见，避免每个动画像素变化都重新组合整页。

输入法期间在初始指针事件阶段拦截金额键盘触控，并清除其对外读屏语义，防止误操作；按键样式保持稳定，不因输入法出现切成灰色。未增加独立定时器或第二套动画曲线。系统键盘、厂商输入法和实际掉帧仍需真机验证，本机不提供未经测量的帧率提升结论。

依据：[Android窗口边衬处理](https://developer.android.com/develop/ui/compose/system/insets-ui)。

验证：67项单测、50项原生截图及构建通过。新增高度注入布局检查（0/100/320像素）和组合生命周期探针，高度变化期间键盘内容创建与组合均为1次。静态布局与探针不等同于真机帧率验证；adb当前无连接设备。Lint为0错误、7项既有警告、1条信息。

## 1.1.9 备注直接输入

备注栏使用单行BasicTextField，在原位置直接输入，不再使用添加备注弹窗。内容实时同步账单草稿，最多50字，聚焦时显示字数；新增、编辑账单均复用此输入框。

系统输入法出现时暂时隐藏四列金额键盘，使用IME内边距让备注停留在输入法上方。输入法「完成」或页面顶部「完成」清除焦点并关闭输入法，随后恢复金额键盘。系统返回优先结束文字输入，输入内容仍留在草稿中；离开页面继续遵循未保存修改确认。

67项单测通过。截图覆盖空备注、已有备注、聚焦字数、多主题和大字号，共46项。截图基于Layoutlib，不验证真实输入法；中文输入法候选词、遮挡与返回交互尚需手机安装后确认。

1.1.9构建及签名校验通过，Lint为0错误、7项既有警告、1条信息。APK为 `app/build/outputs/distribution/xiaozhuheng-v1.1.9.apk`，35,995,651字节，versionCode14，包名和签名保持一致。SHA256：`43892193c7f32a22c0fd33b1961c00e5cbd15eb51f5b3999ae52afdeed7b24ab`。

记账页保留原有收支类型、金额和分类区，去掉「选择分类 / 管理」行。备注改为数字键盘上方的整行输入框，支持长内容横向滚动。分类管理通过设置进入。

四列键盘右侧依次为日期、加号、减号、保存。原先「再记」和编辑时的「清零」入口不再显示；EditViewModel.save(continueEntry=true)、SaveResult.CONTINUE及保存后重置逻辑保留。

支持按从左到右的顺序连续加减，例如12.30+8.20-1.60=18.90。金额上方的小字显示算式，大字显示计算结果；点击保存直接记录结果，不单独存储算式。收入/支出仍由类型选择决定。

每个操作数最多8位整数和2位小数，使用BigDecimal转整数分后运算，不使用浮点数。重复点击运算符替换末尾符号；退格逐字删除，可撤回符号。算式长度限制160字符，最终金额必须大于0且不超过99,999,999.99；不完整算式阻止保存并参与返回时的未保存判断。允许中间结果为负或超上限，只校验最终保存值。

本次不改变数据库结构或历史账单。新建、编辑、保存后继续的重置路径共用金额状态机。
