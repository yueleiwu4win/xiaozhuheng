# 记账键盘与加减计算（1.1.9）

## 1.1.9 备注直接输入

备注栏使用单行BasicTextField，在原位置直接输入，不再使用添加备注弹窗。内容实时同步账单草稿，最多50字，聚焦时显示字数；新增、编辑账单均复用此输入框。

系统输入法出现时暂时隐藏四列金额键盘，使用IME内边距让备注停留在输入法上方。输入法「完成」或页面顶部「完成」清除焦点并关闭输入法，随后恢复金额键盘。系统返回优先结束文字输入，输入内容仍留在草稿中；离开页面继续遵循未保存修改确认。

67项单测通过。截图覆盖空备注、已有备注、聚焦字数、多主题和大字号，共46项。截图基于Layoutlib，不验证真实输入法；中文输入法候选词、遮挡与返回交互尚需手机安装后确认。

记账页保留原有收支类型、金额和分类区，去掉「选择分类 / 管理」行。备注改为数字键盘上方的整行输入框，支持长内容横向滚动。分类管理通过设置进入。

四列键盘右侧依次为日期、加号、减号、保存。原先「再记」和编辑时的「清零」入口不再显示；EditViewModel.save(continueEntry=true)、SaveResult.CONTINUE及保存后重置逻辑保留。

支持按从左到右的顺序连续加减，例如12.30+8.20-1.60=18.90。金额上方的小字显示算式，大字显示计算结果；点击保存直接记录结果，不单独存储算式。收入/支出仍由类型选择决定。

每个操作数最多8位整数和2位小数，使用BigDecimal转整数分后运算，不使用浮点数。重复点击运算符替换末尾符号；退格逐字删除，可撤回符号。算式长度限制160字符，最终金额必须大于0且不超过99,999,999.99；不完整算式阻止保存并参与返回时的未保存判断。允许中间结果为负或超上限，只校验最终保存值。

本次不改变数据库结构或历史账单。新建、编辑、保存后继续的重置路径共用金额状态机。
