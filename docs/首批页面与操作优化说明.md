# 首批页面与操作优化

确认范围：优化项 01—08、12；视觉方向为暖白墨绿。

## 页面与操作

- 首页：月度概览显示支出、收入、结余；概览独立于搜索和筛选，筛选结果另列合计。
- 搜索与筛选：顶部固定入口，分类在底部面板选择；切换收支清除不匹配分类，选择分类同步收支类型。
- 明细：分类与备注分行，金额显示收支符号；每天分别展示收入与支出合计。
- 导航：明细、统计、设置三项；首页右下角记一笔，记账与分类管理页隐藏底部导航。
- 记账：支出/收入与金额固定在上方，分类独立滚动；底部四行四列键盘，右列依次为日期、备注、再记、保存。编辑已有记录时“再记”改为“清零”，仅清空当前输入金额。
- 日期与备注：日期默认今天，支持昨天和日历选择，跨年日期补充年份；备注在弹窗中编辑，键盘显示是否已填写。
- 保存：写入期间禁用操作；保存或修改成功直接返回，保存并再记清空金额和备注、保留分类、类型与日期。成功后不显示提示条，失败时保留错误提示。
- 返回：比较原记录与当前金额、分类、类型、日期、备注；有修改时确认放弃，未修改时直接退出。
- 页面切换：根导航始终保持全屏，底部导航与记账入口属于各自主页面；记账页进入和返回直接切换，取消滑动与淡入淡出。退出时仅拦截重复操作，不让按钮先变灰、不清空表单，避免导航栏改变退出页面高度。
- 删除：明细和编辑页共用删除流程，二次确认后执行；成功直接更新列表，编辑入口返回原列表，不提供成功提示与撤销。
- 外观：暖白底、墨绿重点、统一卡片与等宽数字；背景蒙层跟随应用主题，账单内容使用稳定底色。

## 自动验证

使用 JDK 17 执行：

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

14 项单元测试覆盖收支合计、负结余、大额整数分、收入日小计、筛选联动、未保存修改判断和金额输入/重置。

APK：`app/build/outputs/apk/debug/app-debug.apk`（调试签名）。

## 待设备验收

当前没有连接手机或模拟器，以下项目需在设备上确认：

1. 首页输入备注关键词、切换收支和分类，月度概览保持整月口径，结果合计对应筛选记录。
2. 保存并再记连续录入；返回空白表单直接退出，修改已有记录后返回出现放弃提示。
3. 四列键盘右列的日期、备注、再记、保存均可使用；编辑页清零不直接写入数据库，保存修改后再回到列表。
4. 备注弹窗完成、取消及系统返回正确收起系统键盘；小屏与大字体下分类能滚动，金额固定可见。
5. 进入记账后直接返回、保存后返回、放弃修改后返回，以及分类管理往返，页面没有突然缩短或组件提前消失。
6. 左滑删除与编辑页删除均先二次确认；取消保留原记录，确认成功后不出现提示条和撤销，编辑页返回原列表。
7. 系统浅色/应用深色、系统深色/应用浅色，以及自定义背景下文字可读、蒙层正确。
