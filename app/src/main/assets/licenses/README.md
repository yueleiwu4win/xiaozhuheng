# 主题字体

`res/font/song_headings.ttf` 是 Noto Serif SC 的 600 字重静态标题子集，约 267 KiB。
来源：https://github.com/google/fonts/tree/main/ofl/notoserifsc 。
按 SIL Open Font License 1.1 分发，许可见 `NotoSerifSC-OFL.txt`。
修改后的字体族名称为 `Xiaozhuheng Song Headings`。

仅用于短标题；正文与金额使用系统字体。子集包含当前 Kotlin 页面文案中的字符和 ASCII，其他字符由 Android 字体回退处理。
